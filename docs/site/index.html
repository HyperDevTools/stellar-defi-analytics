02 / Reading a metric

Three checks before trusting a chart.

A metric is only as useful as its definition, source, and timestamp. Treat those as first-class parts of the display.

Find the source

Identify the Horizon endpoint, contract, indexer, oracle, or static fixture behind the value. A constant is not an observation.

Check the method

Read the implementation and inputs. Sample trades and assumed prices cannot establish a wallet's actual return.

Check the time

Require a clear update timestamp and freshness policy before describing any feed as live or current.

03 / Run locally

Explore the application safely.

For development, keep the default network on testnet and never put secret keys or signing credentials in public environment variables.

git clone https://github.com/HyperDevTools/stellar-defi-analytics.git
cd stellar-defi-analytics
npm install
npm run dev

Open http://localhost:3000. Read the API notes and contribution guide; validate any data pipeline independently before using its output.
